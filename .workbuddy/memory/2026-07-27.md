## 实施 Terminal UI 高保真原型（v0.9「聪明」）

把 `docs/ui-concept.html` 的「航站楼」设计稿落地到真实主界面。

### 修复的断点
- **HeroTerminal.ctx 遮蔽 bug**（`initHeroTerminal(ctx)` 参数名与模块级 `ctx` 重名，画布动画永远不运行）→ 改参数为 `_deps`
- **Hero 翻牌钟静态冻结** → 改为 `heroTargetTs` 时间戳方案，每秒重算 remaining
- **Hero 数据未接线** → main.js 中新增 `refreshHero()`：用 `getNextUpcomingTask()` 计算 `seconds/flightNo/label/msg/departInfo`，每 5s 校准
- **FlightBoard 筛选失效、_remaining 缺失、parseInt 风险** → 重写 FlightBoard.js：应用 keyword/type/group 筛选、用 `getAllUpcomingTasks()` 给每行加剩余秒、状态语义补全 `hold`（候机中）

### 新增模块
- `src/flight/Snooze.js` — 轻量 in-memory 推迟 Map（taskId → untilTs），`snoozeTask/isSnoozed/clearSnooze`
- AlarmChecker 触发前 `if (isSnoozed(task.id)) return` 跳过
- FlightBoard 行操作 `postpone` 对接 snooze（10 分钟）+ countdown 暂停/继续

### 渲染管线修复
- `setFlightBoardRenderer` 必须在 `runPostInit` **之后**注册（否则首次 renderTaskView 时 FlightBoard 还没接管），并立刻 `refreshBoard()` 替换占位卡片
- `renderTaskView` 现在双渲染（TaskRenderer 写卡片 → FlightBoard 覆盖），效果是 FlightBoard 单源

### 命令面板修复
- ⌘K 冲突：KeyboardShortcuts 的 case 'k' 改为 no-op，让 CommandPalette 接管
