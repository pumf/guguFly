01

概念映射：一切皆是航班

现有功能无需重做，只换一层"皮"——但用户对产品的理解成本直线下降，记忆点直线上升。

旧概念（通用 Todo）新概念（航空隐喻）
任务→航班（自动分配航班号 GG xxxx）
任务列表→航班信息板（Departures Board）
即将起飞分组→「即将登机」状态 + 琥珀色脉冲
任务被智能暂停推迟→「延误」，并说明原因（会议中）
禁用任务→「已取消」航班（划线 + 灰显）
飞行统计→航行日志 / 里程数
紧急降落→保留 —— 已经是最好的隐喻 👍
新建任务→「签发新航班」，表单=登机牌样式
02

四条设计原则

🛫

隐喻贯穿到底

文案、状态、空页面全部使用航空语言。用户不是"管理任务"，而是"运营一座私人机场"。

⚡

三秒原则

打开窗口 3 秒内必须知道"下一班几点飞"。Hero 大卡片 + 翻牌倒计时永远置顶。

👁️

改即所见

外观、声音、轨迹设置全部实时预览，消灭"下拉框猜谜"。飞行预览窗常驻设置旁。

🕊️

温和打断

UI 动效 ≤ 300ms 且可预期。全应用唯一的"重动效"是飞行本身——那是主角。

03

色彩：夜间机场 × 清晨机场

深色优先——机场最美的时刻是夜晚。琥珀色取自跑道灯与候机厅灯光，青蓝取自夜空与航显屏。

夜空 Navy#0B1226 · 主背景
跑道灯 Amber#FFB454 · 主强调
航显屏 Cyan#4CC9F0 · 信息色
准点绿 Green#5EE0A0 · 成功态
延误橙 Orange#FF8F6B · 警示态
纪念粉 Pink#F27EA9 · 纪念日
04

关键交互升级

⌘K

命令面板

搜索航班、立即起飞、新建、进专注模式、跳设置——一个入口全部完成。重度用户的手不再离开键盘。

📹

智能时机横幅

检测到会议/全屏/录屏时，航班自动"延误"并给出明确原因；结束后一键补飞。每一次推迟都在用户知情下进行，信任不被透支。

🃏

翻牌时钟（Split-flap）

倒计时数字采用机场航显屏经典的翻牌动画，是整套 UI 的"签名动效"——截图即有辨识度。

🛝

行内快捷操作

悬停航班行浮现：立即起飞 / 推迟 / 详情。高频操作不再进二级页面，列表操作步数从 3 步降到 1 步。
