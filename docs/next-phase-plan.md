# 咕咕机长 · 下期开发计划（v0.9 → v1.0）

> 版本现状：v0.8.1，Tauri 2 + Vite + 原生 JS。
> 核心功能（4 类任务、8 节奏 / 6 飞机 / 6 尾焰 / 6 文案框、12 音色、农历、深色、统计、URL Scheme、全局快捷键、飞行后操作）已落地。
> 本文基于 `src/` 代码探查，聚焦**真正能提升价值的缺口**，按优先级分三阶段推进。

---

## 一、现状关键缺口（规划依据）

| 缺口 | 证据 | 影响 |
|---|---|---|
| 旗舰功能零测试 | `QuickCreateParser.js`、`PomodoroTimer.js`、`HolidayPresets.js` 无任何单测（22 个测试覆盖其余模块） | 自然语言创建、番茄钟、节气判断回归无保障 |
| 主窗口无响应式 | `style.css` 仅 1 处 `@media (max-width:480px)`（`style.css:3226`），`index.html` 无 resize 处理 | 桌面小窗/缩放体验差，迷你窗双份维护易漂移 |
| i18n 未收口 | `FlightTrigger.js:12`、`UpdateManager.js:209/245`、`utils.js:6` 硬编码中文兜底 | 英文模式下 toast / 确认框仍露中文 |
| 统计为"简化版" | `StatsPanel.js:100-142` 全量重算 + `HistoryPanel.js:73` O(n²) 历史聚合 | 数据量大时卡顿，洞察浅 |
| 初始化顺序脆弱 | 多个模块 `let showToast = msg => console.warn('before init')` 守卫（`QuickCreateBar.js:5` 等） | 模块注入顺序隐性耦合，易出"未初始化" bug |

## 二、阶段一 · v0.9.0 打磨地基（P0，低风险快交付）

### 1. 旗舰功能补测试
- **功能**：为 `QuickCreateParser`（中文时间"三点/三点钟"解析）、`PomodoroTimer`（工作/短休/长休/轮次切换）、`HolidayPresets`（法定 + 二十四节气、农历判断）补齐单测；CI 加测试通过卡点。
- **界面 / 操作**：无直接 UI 改动。
- **价值**：守住旗舰能力，为后续重构（i18n / 响应式）提供安全网。
- **工作量**：约 1 周。

### 2. 主窗口响应式 + 常驻迷你条
- **功能**：主窗口随拖拽缩放自适应布局（窄窗任务列表转单列卡片）；新增"桌面常驻迷你条"——吸附屏幕边缘、透明度可调、不抢焦点，复用 `public/mini.html` 思路但**统一进 Vite 构建**消除双份维护。
- **界面**：窄窗折叠为单列卡片流；迷你条为轻量控件，支持贴左/右/下边。
- **操作**：拖窗口边缘缩放即生效；设置里开关"常驻迷你条"并选位置。
- **价值**：桌面工具核心体验——随时可见、不必开大窗。
- **工作量**：约 1.5 周。

### 3. i18n 收口
- **功能**：统一 `t()` 参数化（替换 `StatsPanel.js:94` 的手写 `.replace`），消除 `FlightTrigger / UpdateManager / utils` 硬编码中文兜底。
- **界面 / 操作**：英文模式下全部 toast / 确认框不再露中文。
- **价值**：为国际化与后续"主题市场 / 分享"铺路。
- **工作量**：约 0.5 周。

### 4. 初始化顺序解耦
- **功能**：用显式依赖注入替换 `before init` 守卫（`main.js` 模块注入重构）。
- **界面 / 操作**：无感知。
- **价值**：降低隐性 bug，提升可维护性。
- **工作量**：约 0.5 周。

## 三、阶段二 · v0.9.x 智能预览（P1，体验跃迁）

### 5. 数据洞察面板升级
- **功能**：增量更新 + 缓存替代全量重算；新增周/月趋势折线、连续飞行天数（streak）、最常用音色 / 飞机、专注时长；**每周一自动弹"上周复盘"飞行**。
- **界面**：复用现有统计面板结构，新增趋势区 + 周复盘小结卡。
- **操作**：点"统计"看趋势；周一自动收到复盘飞行。
- **价值**：把"提醒工具"升级为"陪伴型效率伙伴"，呼应 v1.0 数据洞察。
- **工作量**：约 2 周。

### 6. 情景模式（Scene / Profile）
- **功能**：一套情景 = 任务集 + 主题 + 音色 + 飞行预设组合（如"工作专注""生活碎片""节假日"），可自定义。
- **界面**：主界面顶部新增情景切换胶囊。
- **操作**：一键切换；设置里增删改情景。
- **价值**：多角色用户（工作/生活）一键切换，显著提升粘性。
- **工作量**：约 1.5 周。

### 7. 专注工作流整合
- **功能**：番茄钟与飞行打通——"开始 25 分钟专注"→ 飞机盘旋显示环形剩余进度，结束放"成功"音色 + 复盘。
- **界面**：飞行窗口内显示环形进度；任务卡新增"专注"按钮。
- **操作**：任务卡点"专注" / 全局快捷键启动番茄。
- **价值**：把唯一差异化（飞行）嫁接到高频生产力场景。
- **工作量**：约 1.5 周。

### 8. 本地重复学习建议（AI 轻量版）
- **功能**：基于本地历史，识别重复模式（如"常在 9:00 设会议提醒"）主动建议，无需云端/大模型成本。
- **界面**：主界面空态 / 新建任务时弹出"智能建议"气泡。
- **操作**：点建议一键创建。
- **价值**：以零成本验证 v1.0 的"AI 智能建议"卖点。
- **工作量**：约 1 周。

## 四、阶段三 · v1.0 Pro 基石（P2，战略验证）

### 9. 飞行编排可视化编辑器
- **功能**：在飞行设置中用 SVG/Canvas 预览轨迹并拖拽调节点（弧线 / 心形 / 8 字关键点），所见即所得。
- **界面**：替换现有"下拉选节奏"为"预览 + 微调"面板。
- **操作**：拖动轨迹控制点实时预览。
- **价值**：强化唯一差异化卖点，为"主题市场"创作者工具奠基。
- **工作量**：约 2.5 周。

### 10. 云端备份 MVP（WebDAV，本地优先）
- **功能**：手动 / 定时将任务 JSON 备份到 WebDAV（Nextcloud / 群晖等），恢复时版本对比（diff 预览）。
- **界面**：设置 → 备份 新增 WebDAV 配置区；恢复有 diff 预览。
- **操作**：填地址 / 账号 → 测试连接 → 启用自动备份。
- **价值**：v1.0 Pro 核心付费点，先以通用协议低成本验证。
- **工作量**：约 2 周。

### 11. 主题导入 / 导出 + 多设备同步雏形
- **功能**：主题包导出为可分享文件；打通 WebDAV 实现多设备任务同步。
- **界面**：设置 → 主题 / 备份 复用配置区。
- **操作**：导出主题文件分享；登录 WebDAV 自动同步。
- **价值**：为"主题市场 + 分成"和"家庭共享清单"铺路。
- **工作量**：约 1.5 周。

## 五、下期建议范围（聚焦交付）

**v0.9.0 必做**：① 旗舰补测试 ② 主窗响应式 + 常驻迷你条 ③ i18n 收口 ④ 初始化解耦
**v0.9.x 重点**：⑤ 数据洞察升级 ⑥ 情景模式 ⑦ 专注整合 ⑧ 本地建议
**v1.0 打样**：⑨ 飞行编辑器 ⑩ 云备份 WebDAV ⑪ 主题/同步

> 不建议下期做（留 v1.0+）：AI 大模型建议（先以本地轻量版替代）、主题市场 + 分成（先有编辑器 + 导入导出）、家庭共享清单（协作后端成本高）。
