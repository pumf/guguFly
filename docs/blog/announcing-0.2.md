# 桌面端终于等来一个"不吵人"的提醒工具：咕咕机长 0.2 发布

> 一只会飞的桌面提醒器 ✈️ 让"该干活了"变成一件好玩的小事。

---

## 写在前面

你有没有这样的时刻——

正在写代码、写文档、做设计，沉浸在自己手上的事情里。**突然**：叮——一个 5MB 体积的提醒弹窗跳出来，带着大红叉，**咔嚓**一声抢走了你的键盘焦点。**你骂了一句，又点了 5 个"知道了"才能继续工作**。

或者更糟：开着 12 个 Tab 做调研，浏览器角落悄悄弹出一个"会议 5 分钟后开始"——但你没看见，因为光标在另一个窗口。

市面上 90% 的提醒工具都是这样。**咕咕机长** 想做点不一样的。

咕咕机长 0.2.0 正式发布。它不做弹窗、不抢焦点、不发系统通知 — **它让飞机从屏幕左边飞过去，告诉你该做什么。**

## ✨ 这次更新了什么

v0.2 是 5 个月迭代的最大一次更新，从 0.1 的"能跑"到 v0.2 的"用得顺手"。

### 🎯 桌面原生，不抢焦点

飞行窗口是**独立透明层**，叠加在所有应用之上。触发时飞机从屏幕左侧飞过，文案框跟着滑过，关屏也能看到 — **不会打断你正在做的事**。

支持 **macOS / Windows / Linux** 三平台，**Apple Silicon 安装包仅 4.5MB**。

---

### 🎨 144 种飞行组合

[图：飞行设置抽屉](https://github.com/pumf/guguFly/raw/main/docs/screenshots/flight-settings.png)

**5 种飞行效果**：
- 🚀 经典直穿 — 直线划过，干脆利落
- 🌊 自然滑过 — 带轻波动，最常用
- 🎭 仪式感（弧线）— 飞机先下沉再飞过，适合重要事项
- ⚡ 利落提醒 — 快速擦过，适合高频小提醒
- 🎈 活泼一点（S 形）— 上下波动，适合节日和纪念日

**6 套飞机**（经典/火箭/蝴蝶/喷射/纸飞机/飞碟）× **6 套尾焰**（飘带/火焰/星点/尾迹/闪光/云团）× **6 套文案框**（圆角/锐角/柔圆/简约条/玻璃感/贴纸感）= **144 种组合**。

不满意？**上传你自己的图片**（PNG/JPG/GIF）和**音频**（mp3/wav/ogg）— 飞行时用你上传的素材。

---

### 🔊 12 个内置音色

v0.2 把音色从 6 个翻倍到 **12 个**：咻 / 叮咚 / 铃声 / 柔和 / 风铃 / 脉冲 / **鸟鸣** / **钟声** / **成功** / **水泡** / **激光** / **晨光**。

全部由 Web Audio API **代码合成**（不打包任何音频文件），体积小到可以忽略。

---

### 🎨 颜色标签 + 任务级图片

[图：任务列表颜色条](https://github.com/pumf/guguFly/raw/main/docs/screenshots/home.png)

8 种预定义颜色（红/橙/黄/绿/青/蓝/紫/粉）让任务视觉分类 — **番茄钟用绿、晨会用蓝、纪念日用粉**。

每条任务还能上传**自己的图片**（覆盖全局图片），适合：
- 把"会议"任务附上你团队的 logo
- "结婚纪念日"附上结婚照
- 重要会议用 GIF 飞过

### 🔌 集成其他 App

```bash
# 从 Slack / 终端 / Alfred 唤起创建任务
open "gugufly://add?msg=下班了&type=alarm&hour=18&minute=0"
open "gugufly://add?msg=番茄钟&type=countdown&mins=25"
open "gugufly://add?msg=结婚纪念&type=anniversary&month=5&day=20"
```

**URL Scheme** `gugufly://add?msg=...` 让你从任何地方创建任务。

**全局快捷键**（macOS）`⌘⌥S` 开始 / `⌘⌥P` 暂停 / `⌘⌥Q` 停止所有倒计时。**`ESC`** 一键紧急降落（停止所有飞行 + 清空 streak）。
