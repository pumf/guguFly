> 版本: 0.8.1 | 制定日期: 2026-07-16 | 规划周期: v0.9 → v1.3（约 12-18 个月）

## 一、产品定位与市场分析

### 1.1 核心定位

咕咕机长是一款**以桌面飞行动画为差异化核心的跨平台定时提醒工具**。它把枯燥的提醒通知转化为有仪式感的桌面动画体验，在功能工具和情绪价值之间找到了独特的平衡点。

### 1.2 当前能力（v0.8.1）

| 维度 | 能力 |
|------|------|
| 任务类型 | 定时闹钟、倒计时、节假日（含农历）、纪念日（含农历） |
| 飞行表现 | 8 种飞行节奏、6 套机型、6 套尾焰粒子、6 套文案框、4 级速度 |
| 音效 | 12 种内置音色 + 自定义音频上传 |
| 桌面体验 | 全屏置顶飞行窗口、迷你悬浮窗（6 位置）、托盘菜单、深色主题 |
| 集成 | URL Scheme `gugufly://`、全局快捷键、系统通知、飞行后操作（锁屏/开应用/语音/脚本/URL） |
| 数据 | JSON 导入导出、90 天飞行日志、番茄钟 |
| 跨平台 | macOS (Intel + AS)、Windows、Linux |

### 1.3 核心优势与短板

**优势**：
1. **飞行动画** — 真正的差异化，不是弹文字而是飞机飞过去
2. **农历支持** — 中国用户刚需，竞品普遍缺失
3. **开源+本地优先** — 隐私友好，无需注册
4. **跨平台** — 大多数桌面宠物/提醒工具仅 macOS
5. **URL Scheme** — 开发者友好，支持自动化
6. **高度可定制** — 飞机/粒子/音效/文案框全可换

**短板**：
1. **无云同步** — 换设备丢数据，用户最大痛点
2. **无移动端** — 无法在 iPhone/Android 上查看/管理任务
3. **安全漏洞** — XSS、CSP 过宽、命令注入风险（见 project-review.md）
4. **工程化不足** — main.js 过重、无框架、状态分散、测试覆盖率有限
5. **无日历集成** — 不能读写系统日历，职场用户期望
6. **无健康提醒** — 久坐/喝水/护眼等场景缺失
7. **无专注模式** — 不屏蔽干扰应用/网站

**市场空白**：目前没有一款产品同时具备——
- ✅ 飞行动画通知（不是宠物走动，而是飞机飞行穿越）
- ✅ 农历节假日/纪念日支持
- ✅ 跨平台（macOS + Windows + Linux）
- ✅ 开源 + 本地优先
- ✅ URL Scheme 开发者集成

### 1.5 目标用户画像

1. **效率爱好者**（核心用户）：喜欢工具、愿意折腾配置、追求个性化和仪式感
2. **远程办公/自由职业者**：需要自行管理时间节奏，桌面提醒是刚需
3. **学生群体**：番茄钟、考试倒计时、课程提醒
4. **团队/小企业**（扩展用户）：需要轻量团队提醒，但不想上重型项目管理工具

## 二、战略愿景

> 成为**桌面端最有趣、最值得信赖的时间管理伙伴**——不只是提醒工具，而是用户桌面上有温度、有个性的存在。

**三年目标**：
- 年活用户 50 万+
- 开源社区贡献者 100+
- Pro 付费转化率 3-5%
- 插件生态初步成型（50+ 社区插件）

### 核心战略：「飞行动画 + 温和提醒」双引擎

飞行动画是灵魂，温和提醒是增长引擎。两者组合才是咕咕机长的护城河。

| 引擎 | 作用 | 对应功能 |
|------|------|---------|
| 飞行（灵魂） | 用户第一印象、口碑传播、记忆点 | 飞行节奏/机型/粒子/自定义图片/着陆互动 |
| 温和提醒（增长） | 满足日常高频需求，从极客扩展到大众 | 久坐/喝水/护眼/日历/番茄钟/健康养成 |

**不做**的事：
- 不做纯番茄钟（赛道拥挤，无差异化）
- 不做桌面宠物（NotiSprite 已做得很好，飞机飞行才是独特体验）
- 不做锁屏强制提醒（过于激进，与「趣味温和」定位冲突）
- 不做 AI 对话宠物（BitCat 在做，且偏离提醒工具核心）

## 六、v1.1 — 生态开放（2027 Q1-Q2，8-10 周）

> **主题**：从一个人的项目变成一群人的平台。插件系统 + 社区市场 = 指数级内容增长。

### 6.1 插件系统 🔥🔥🔥

最具战略价值的功能。建立标准化的插件接口，让社区贡献飞行路径、飞机样式、粒子效果、声音包、提醒逻辑。

```
插件类型           API 复杂度    示例
─────────────────────────────────────────────
飞行路径           低           «∞» 符号路径 / 弹跳路径 / 旋绕 logo 路径
飞机皮肤           低           「老板来了」「摸鱼警告」主题飞机
粒子效果           低           樱花飘落 / 金币雨 / 雪花
声音包             低           白噪音合集 / ASMR / 8-bit 游戏音效
文案框样式         低           Markdown 渲染 / 代码块风格 / 漫画气泡
触发条件           中           「CPU > 80%」「股价 > N」触发
扩展操作           中           「飞行后更新 Slack 状态」
数据源             高           接入 Jira/GitHub Issues 作为任务源
```

**技术方案**：
- 插件为纯 JS 模块，通过标准化接口注册

## 九、优先级排序逻辑


## 十三、总结

咕咕机长的核心价值不是「提醒你」，而是**「用最好玩的方式提醒你」**。

产品发展的关键路径：

1. **先修好地基**（安全、稳定、工程化）—— 不安全的开源软件没有未来
2. **再补齐痛点**（云同步）—— 这是用户流失的头号原因
3. **然后强化差异化**（飞行动画 2.0）—— 这是别人做不到的事
4. **接着打开增长**（健康提醒 + AI）—— 从极客扩展到职场大众
5. **最后构建生态**（插件 + 市场 + 移动端）—— 有用户基数才做

每一步都建立在前一步的基础上，不跳跃，不追风口，扎实做好每一个版本。
