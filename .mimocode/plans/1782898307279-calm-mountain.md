# 修复 i18n 翻译问题计划

## 问题概述
1. 语言默认未选择中文
2. 详情侧边栏和任务编辑框显示 `{{status}}`、`{{summary}}`、`{{key}}` 等原始占位符
3. 大量硬编码中文字符串未使用 `t()` 翻译函数

## 根因分析

### 占位符显示问题
`t()` 函数在缺少参数时会保留 `{{key}}` 原文。调用方传入了翻译 key 但未传递参数对象。

### 硬编码字符串问题
代码中直接使用中文字符串而非 `t()` 翻译函数，导致非中文语言下仍显示中文。

## 修改方案

### 1. 默认语言设为中文
**文件**: `src/i18n/index.js`
- 在 `initI18n()` 中，如果 localStorage 和 navigator 都没有设置语言，默认使用 `'zh-CN'`（当前逻辑已如此，但需要确认 bootstrap.js 中的 `setLanguage` 调用不会覆盖）

### 2. 修复 TaskDetailDrawer.js 硬编码
**文件**: `src/ui/TaskDetailDrawer.js`
- Line 74: `['周日', '周一'...]` → 使用 `ta('calendar.day_labels')`
- Line 75: `每周${...}` → 使用 `t('task.detail.repeat_weekly', { days })`
- Line 77: `每月${repeat.day}号` → 使用 `t('task.detail.repeat_monthly', { day })`
- Line 81: `每${repeat.interval}天` → 使用 `t('task.detail.repeat_interval', { interval })`
- Line 109,121-122,126-127: `飞行统计`/`次` → 使用 `t('stats.flight_count')` 等

### 3. 修复 ModalController.js 硬编码
**文件**: `src/ui/ModalController.js`
- Line 103: `'编辑任务'` → `t('modal.edit_task')`
- Line 231: `'新建任务'` → `t('modal.new_task')`

### 4. 修复 TaskRenderer.js 硬编码
**文件**: `src/ui/TaskRenderer.js`
- Line 290: `'删除'` → `t('common.delete')`
- Line 362,373,376,383: 按钮标题使用 `t()` 翻译
- Line 497: `(副本)` → `t('task.copy_suffix')`

### 5. 修复 StatsPanel.js 占位符问题
**文件**: `src/ui/StatsPanel.js`
- Line 94: 修复 `.replace('{{count}}', ...)` 调用，使用正确的翻译 key

### 6. 修复 HistoryPanel.js 硬编码
**文件**: `src/ui/HistoryPanel.js`
- 使用 `t()` 翻译所有硬编码字符串

### 7. 修复 bootstrap.js 硬编码
**文件**: `src/app/bootstrap.js`
- Line 127,177: 使用 `t()` 翻译计数字符串

### 8. 修复 FlightTrigger.js 硬编码
**文件**: `src/flight/FlightTrigger.js`
- Line 10: 使用 `t()` 翻译

### 9. 修复 main.js 硬编码
**文件**: `src/main.js`
- Line 749: `(再来一次)` → `t('task.repeat_suffix')`

### 10. 新增翻译 key
**文件**: `src/i18n/translations/zh-CN.js` + `en.js`
- `task.detail.repeat_weekly`: `每周{{days}}` / `Weekly {{days}}`
- `task.detail.repeat_monthly`: `每月{{day}}号` / `Monthly on {{day}}`
- `task.detail.repeat_interval`: `每{{interval}}天` / `Every {{interval}} days`
- `stats.flight_count`: `飞行统计` / `Flight Stats`
- `stats.loading`: `加载中...` / `Loading...`
- `stats.times`: `{{count}} 次` / `{{count}} times`
- `modal.edit_task`: `编辑任务` / `Edit Task`
- `modal.new_task`: `新建任务` / `New Task`
- `task.copy_suffix`: `(副本)` / `(copy)`

## 验证方式
1. 重启应用，确认默认语言为中文
2. 点击任务卡片打开详情侧边栏，确认无 `{{}}` 占位符
3. 打开任务编辑框，确认标题和按钮文字正确
4. 切换到英文，确认所有文字正确翻译
